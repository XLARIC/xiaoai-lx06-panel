# 小爱音箱 LX06 管理页

简体中文 · [English](README.en.md)

**让小爱按你所在的时区报时间和日期，并播报你所在地点的天气。** 在小爱音箱 Pro 的局域网管理页里，手机或电脑连上同一个 Wi-Fi 就能修改这些设置，也可以管理蓝牙和双音箱同步。

## 修正报时、日期和天气预报

- **报时与日期**。选择所在地的 IANA 时区，例如奥克兰用 `Pacific/Auckland`。小爱回答「现在几点了」和「今天几号」这类问题时，会使用所选时区处理当地时间和日期，适用于在不同时区使用音箱的场景。
- **天气预报**。填写所在地的经纬度作为默认天气位置。问「今天天气怎么样」时，小爱会用这个位置查询天气，平时省去每次指定城市。

## 支持范围

- 目前面向小爱音箱 Pro（LX06）固件 1.94.13。安装器会检查系统文件的校验值，遇到不匹配的设备时会停止。
- 安装前需要已有 root SSH 访问权限。刷机和开启 SSH 请参阅 [原版 Open-XiaoAI 刷机教程](https://github.com/idootop/open-xiaoai/blob/main/docs/flash.md)及 [LX06 1.94.13 上游发行版](https://github.com/idootop/open-xiaoai/releases/tag/LX06_1.94.13)。
- 已在一台此前配置好的 LX06 上验证 QQ 音乐和 LG PL7 双播，空闲时管理页实测常驻内存约 3.7 MB。这个发行包的首次安装流程和重启后的行为仍待实机验证。

## 一键安装

电脑与音箱连到同一个 Wi-Fi。在 macOS、Linux 或 Windows 的 WSL 中使用 OpenSSH。下载 [GitHub Releases](https://github.com/XLARIC/xiaoai-lx06-panel/releases) 中的 `xiaoai-lx06-panel-v0.1.1.tar.gz`，对照附带的 SHA-256 校验文件，然后运行以下命令。将示例 IP 换成音箱的实际局域网地址。

```sh
tar -xzf xiaoai-lx06-panel-v0.1.1.tar.gz
cd xiaoai-lx06-panel-v0.1.1
./install.sh 192.168.1.50
```

首次 SSH 连接时核对主机指纹，并按提示使用音箱已有的 SSH 登录方式。安装完成后，终端会显示管理页地址（端口 `8086`）、用户名和为此次安装生成的独立密码。请保存登录信息。安装器把程序和配置放到音箱的可写数据分区，并设置开机启动。请在信任的局域网内使用这个 HTTP 页面。

## 使用管理页

- **设置位置**。首次使用时，在「位置」里填写经纬度和时区，确认让小米天气和报时服务使用这些数据，再保存到音箱。
- **接收手机音频**。首次安装采用接收模式。在小爱的管理页保持该模式，在手机蓝牙设置里连接小爱。
- **蓝牙输出与同步**。让外接音箱进入配对模式，在网页选择输出模式，再搜索、选择并配对一台外接音箱。切换模式可能会短暂中断正在播放的音乐。小爱和外接音箱会同时播放。同步延迟是给小爱本机加的延迟，可在 0–750 毫秒之间调整，初始值是 320 毫秒。根据听感微调，直到两台声音对齐。
- **先播歌，再打开外接音箱**。外接音箱的蓝牙链路建立后，小爱会自动短暂停歌，接入蓝牙音频后恢复同一首歌。每次连接只自动尝试一次，接入失败时恢复本机播放。若蓝牙链路尚未建立，可以暂停音乐，让小爱主动重连。

如需只检查音箱是否兼容，可先运行 `./install.sh --check 192.168.1.50`，并替换为音箱实际地址。

## LG PL7 配对与回连

LG PL7 进入配对等待时，长按蓝牙键约 2 秒，听到提示音后松开，确认蓝牙图标旁的灯闪烁，再在管理页搜索并选择音箱。具体按键说明见 [LG PL7 官方说明书](https://www.lg.com/content/dam/channel/wcms/pl/support/products/documents/PL7.DEUSLLK_WEB_POL_MFL71448060.pdf)。

若配对成功后仍无法主动回连，可以通过音箱的 SSH 查看并选择是否允许该设备主动连接。运行 `bluetoothctl`，用 `paired-devices` 确认外接音箱的地址，再执行以下命令，将示例地址换成自己的音箱地址。`trust` 会持久允许该设备主动回连，请自行确认这一设置。

```text
info AA:BB:CC:DD:EE:FF
trust AA:BB:CC:DD:EE:FF
quit
```

需要撤回时，在 `bluetoothctl` 中运行 `untrust AA:BB:CC:DD:EE:FF`。

蓝牙连接后若音乐仍处于暂停，可以对小爱说「继续播放」。通过 SSH 续播时，已在测试设备上验证以下指令会恢复当前歌曲，随后应确认播放进度持续增长。

```sh
ubus call mediaplayer player_play_operation '{"action":"play","media":"app_ios"}'
```

## 卸载

在解压后的目录运行以下命令。请替换示例 IP。

```sh
./install.sh --uninstall 192.168.1.50
```

## 从源码构建

安装 Go 1.26.x 和 Zig 0.15.2，然后在项目目录中运行以下命令。

```sh
./scripts/build.sh
```

安装归档和 SHA-256 校验文件输出到 `dist/`。

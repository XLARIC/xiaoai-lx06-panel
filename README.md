# 小爱音箱 LX06 管理页

简体中文 · [English](README.en.md)

在小爱音箱 Pro 上运行的轻量局域网管理页。手机或电脑连上同一个 Wi-Fi，即可在浏览器里调整位置、蓝牙模式和同步延迟。

## 支持范围

- 目前面向小爱音箱 Pro（LX06）固件 1.94.13。安装器会检查系统文件的校验值，遇到不匹配的设备时会停止。
- 安装前需要已有 root SSH 访问权限。刷机和开启 SSH 请参阅 [原版 Open-XiaoAI 刷机教程](https://github.com/idootop/open-xiaoai/blob/main/docs/flash.md)及 [LX06 1.94.13 上游发行版](https://github.com/idootop/open-xiaoai/releases/tag/LX06_1.94.13)。
- 已在一台此前配置好的 LX06 上验证 QQ 音乐和 LG PL7 双播，空闲时管理页实测常驻内存约 3.7 MB。这个发行包的首次安装流程和重启后的行为仍待实机验证。

## 一键安装

电脑与音箱连到同一个 Wi-Fi。在 macOS、Linux 或 Windows 的 WSL 中使用 OpenSSH。下载 [GitHub Releases](https://github.com/XLARIC/xiaoai-lx06-panel/releases) 中的 `xiaoai-lx06-panel-v0.1.0.tar.gz`，对照附带的 SHA-256 校验文件，然后运行以下命令。将示例 IP 换成音箱的实际局域网地址。

```sh
tar -xzf xiaoai-lx06-panel-v0.1.0.tar.gz
cd xiaoai-lx06-panel-v0.1.0
./install.sh 192.168.1.50
```

首次 SSH 连接时核对主机指纹，并按提示使用音箱已有的 SSH 登录方式。安装完成后，终端会显示管理页地址（端口 `8086`）、用户名和为此次安装生成的独立密码。请保存登录信息。安装器把程序和配置放到音箱的可写数据分区，并设置开机启动。请在信任的局域网内使用这个 HTTP 页面。

## 使用管理页

- **设置位置**。首次安装时未设置位置。填写经纬度和 IANA 时区，例如 `Pacific/Auckland`，并在保存前确认让小米天气和报时服务使用这些数据。页面配置保存在音箱上。
- **接收手机音频**。首次安装采用接收模式。在小爱的管理页保持该模式，在手机蓝牙设置里连接小爱。
- **蓝牙输出与同步**。让外接音箱进入配对模式，在网页选择输出模式，再搜索、选择并配对一台外接音箱。切换模式可能会短暂中断正在播放的音乐。小爱和外接音箱会同时播放。同步延迟是给小爱本机加的延迟，可在 0–750 毫秒之间调整，初始值是 320 毫秒。根据听感微调，直到两台声音对齐。

如需只检查音箱是否兼容，可先运行 `./install.sh --check 192.168.1.50`，并替换为音箱实际地址。

## 卸载

在解压后的目录运行以下命令。请替换示例 IP。

```sh
./install.sh --uninstall 192.168.1.50
```

## 从源码构建

安装 Go 1.26.x 和 Zig 0.15.2，然后在项目目录中运行以下命令。

```sh
./scripts/build.sh
```

安装归档和 SHA-256 校验文件输出到 `dist/`。
